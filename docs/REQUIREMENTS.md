# Requirements

| | Needed | Notes |
|---|---|---|
| Computer | Windows 10 or 11, macOS, or Linux | Windows is the main platform |
| Python | 3.10 or newer | Setup checks it and helps you install it |
| Git | Git for Windows (or git on Mac/Linux) | Needed for Save & update |
| Browser | Microsoft Edge on Windows (opens as its own app window); any modern browser elsewhere | |
| Claude Code | Optional | Needed for Chats; uses your own login |
| AI providers | At least one, free ones work | Sign in or add keys in **AI models** |
| Tailscale | Optional, free | Only for using it from your phone or laptop |

Everything runs on your own computer. Your keys stay on it.
